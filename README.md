# Inglés Diario

Tarjetas de frases con repetición espaciada y práctica de pronunciación. Tu progreso es solo tuyo.

## Iniciar sesión

Se inicia sesión únicamente con un token de GitHub:

1. Toca **Iniciar sesión** (arriba) o abre **Ajustes**.
2. Toca **Crea un token**. Se abre GitHub con el permiso `gist` ya marcado. Genera el token y cópialo.
3. Pégalo en la app y toca **Iniciar sesión**.

La app crea un gist privado llamado `ingles-diario-progreso.json` y lo mantiene sincronizado. Si cambias de teléfono o Safari borra los datos, repite los pasos y tu historial vuelve. El token queda solo en ese navegador y se usa únicamente para leer y escribir ese gist. No lo compartas.

Sin iniciar sesión, el progreso queda solo en el navegador (`localStorage`). En iPhone, Safari puede borrarlo si no abres el sitio en ~7 días.

## Respaldo manual

En Ajustes, **Copiar progreso** guarda todo como texto; **Restaurar** lo recupera.
